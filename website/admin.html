Security notes

The service account is only used inside Vercel serverless functions. Clients authenticate with installation-specific secrets; administrator actions require a verified Google identity and a server-side email allowlist.

Never add Firebase service-account JSON, private signing keys or notification secrets to the public GitHub repository or website JavaScript.
InkBridge Operations · Installation metrics are not unique people. Analytics and delivery receipts only become meaningful after the mobile and desktop clients are instrumented.
